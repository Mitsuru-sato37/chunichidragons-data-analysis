# 2026年 中日ドラゴンズ・ドラフト動画 制作引き継ぎ

更新日: 2026-10-24
制作対象: 中日ドラゴンズの2026年ドラフトを、指名結果と現有戦力のデータから読み解くYouTube動画

## 企画の現在地

動画の軸は「中日の現状に対し、今回のドラフトはどのような補強戦略だったのか」。指名選手の紹介だけで終わらせず、選手層・起用実績・指名順位や選手の特徴をつないで、指名全体から見える方向性を分析する。

球団が明言していない意図は断定しない。「球団の意図」と「公開情報から読み取れる分析」を分け、結論の確度と根拠を示す。導入では分析方法の講義をせず、視聴者に問いを提示する。

## ここまでの経緯

1. 当初は「中日の重点補強ポイント3選」をドラフト前のデータから考える企画を検討した。
2. 年齢・登録ポジションの分布だけでは根拠が弱く、投打左右、先発・救援、実際の守備位置や一軍の起用実績も材料にする方針へ進んだ。
3. 話の飛躍を避けるため、ポジションごとの選手数だけでなく、実際に誰がどこでどれだけ起用されたかを先に示し、薄さや役割の偏りを根拠づけることを重視した。
4. ドラフト後は「補強候補を予測する動画」から「実際の指名が現有戦力に対してどんな戦略だったかを分析する動画」へ切り替えた。前シーズンの振り返りは目的化せず、指名意図の根拠になる範囲だけ使う。
5. 指名一覧の全体像、各選手の紹介・分析、投手・野手の役割や選手層との照合、ドラフト全体のまとめを素材化した。選手紹介は原則として指名順に進める。
6. 抽選演出は、渡部海の抽選で楽天に敗れた後、宮原廉をロッテとの抽選で獲得した流れを分かるようにする。宮原の紹介ページ上の順位表記は「1位指名」とし、「外れ1位」は使わない。
7. 宮原廉の1分紹介では数値強調アニメーション案も作ったが、情報量・見やすさに課題が残った。現時点では紹介ページを優先素材とし、未採用案は削除せず試作フォルダに保管した。
8. サムネイルは、分析意図が伝わるテーマと、太い縁取り文字・赤黄の強いコントラストを使うYouTubeらしい見せ方を両立する方向。最新案はDriveの「05_サムネ」にあるv4。

## 推奨する動画の流れ

1. **導入** — 「今回の指名から、中日の補強戦略を読み解く」と問いを提示する。明日のドラフトや今後の補強を考える参考になる内容として位置づける。
2. **指名全体像** — 支配下・育成、順位、選手名、所属、投手／野手などを一画面で把握させる。抽選の経緯は全体像を壊さない短い演出でつなぐ。
3. **指名順の選手紹介** — 各選手の所属・投打・守備位置や投手の役割、確認できる特徴・成績を紹介する。数字は対象リーグ・期間・出典が分かるようにする。
4. **中日の選手層との照合** — 同じ役割の一軍・控え・ファーム選手、年齢や左右、実際の起用状況を必要な箇所で示す。先に「このポジションが不足」と決めつけず、数字と起用から根拠を積み上げる。
5. **指名の意味を考える** — 即戦力、競争、後継、層の厚み、特徴の補完など複数の読みを検討し、何が根拠でどこからが見立てかを明確にする。
6. **全体のまとめ** — 個別選手の説明を指名構成に戻し、ドラフト全体に共通する傾向と、今後の起用を見ないと判断できない点を示す。

シーズン成績は背景情報として必要な分に限る。リーグ間の不要な球団比較や、「こう見なければならない」と視聴者に分析手順を教える説明は入れない。

## 固定化する編集・素材ルール

### 根拠と表現

- **確認済み事実**（公式プロフィール・大会記録・報道）、**集計値**、**分析上の見立て**を区別する。
- 成績は対象期間・リーグ・定義をそろえる。春秋比較は母数も示し、比率だけで評価を断定しない。
- 選手の特長、記録、球種、故障歴、スカウト評価などは出典URL・掲載日・確認日を制作メモに残す。確認できない情報は「未確認」とする。
- 選手の能力評価と球団の編成意図を混同しない。同ポジションというだけで補強意図と結論づけない。
- 既存分析に使った2026年データは、独立ソースとの照合と利用条件の確認を終えるまで公開用の確定値として扱わない。NBDRのPBP日付補正値は独立照合前であることを明記する。
- 写真・映像・記事・音源は、出典と利用許諾を確認する。YouTubeで使えることを、閲覧可能であることだけから推定しない。

### 画面・演出

- YouTubeショートとして投稿する動画は、書き出しを縦型9:16・3分以内にする。投稿前にYouTubeの最新仕様を確認し、書き出し後は解像度・縦横比・尺を実ファイルで確認する。
- 説明用素材は一画面につき一つの主張に絞る。不要な数字や装飾を増やさず、ナレーションで述べる根拠が画面で追える密度にする。
- 守備配置図は球場の形を崩さず、ポジション位置を正確に置く。外野は左翼・中堅・右翼を別々に配置し、投手は主な役割が先発なら先発として示す。
- 動きは静止画の連続を補うアイキャッチ、強調、切り替えに使う。数値を一つずつ大きく出す場合も、背景や補足を読みづらくしない。
- 実写素材を優先し、AI生成らしい人物・球場表現は避ける。ユーザー提供の写真、正規に利用できる公式素材、権利条件が明らかな素材を使う。
- サムネイルは小さく表示しても主題が読める文字サイズとコントラストにする。文字の二重白縁や白飛び、過剰な文字詰めを避ける。
- 選手紹介は指名順で素材を個別に作る。人物画像・固有名・統計は誤りや権利問題があるため、確認できた素材・情報のみ使う。

- Google Driveの作業場所: [#L1ドラフト](https://drive.google.com/drive/folders/1mA5AJzEdN2lI1iYn2YLoJYb8102o1EoH)
- `01_導入・指名一覧`: 表紙、一覧、抽選素材
- `02_選手紹介`: `01_宮原廉` と `02_2位以降の指名選手`
- `03_補強戦略分析`: 09〜25の選手層・起用・戦略分析素材
- `04_共通演出・BGM`: 章区切り、旗、アイキャッチ、BGM
- `05_サムネ`: 最新案v4。旧版は配下の`90_旧案・比較用`
- `90_試作・旧版`: 未採用の宮原紹介・数値強調・抽選演出案。削除せず、採用素材と分ける。
- 静止画・アニメーションは編集しやすいSVGと、DaVinci Resolveに取り込めるPNG／MP4を必要に応じて対で保存する。ファイル名に章・指名順・選手名・用途・版を含める。
- Driveの作業素材とローカル出力を正本だと混同しない。公開用の採用版は`採用`など明確に分け、ローカル保存場所と同期状態を確認する。
- GitHubには制作ルール・進行記録・生成コードなど再利用可能なテキスト中心の資料を置き、元データ、データベース、派生集計、重いPNG／動画は置かない。
