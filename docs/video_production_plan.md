# 1本目の動画制作計画

更新日: 2026-10-21
題材: 2026年中日のドラフト補強ポイント

## 動画の問い

**中日がドラフトで補強すべきポイントはどこか。**

アマチュア選手の実名指名予想ではなく、中日のチーム状況、選手層、起用実績をもとに、ドラフトで補う意味のある役割を検討する。現時点では補強順位を断定せず、遊撃・捕手・先発投手を検証候補として扱う。

## 判断の軸

候補ごとに次を分けて確認する。

1. 現在の主力が役割を果たしているか
2. 控えやファームの選手が役割を代替できるか
3. 次の担い手が必要になる時期
4. ドラフトで獲得する選手の成長期間と必要時期が合うか

主力への出場集中は欠場時のリスクを考える材料であり、それだけでドラフト優先度を決めない。若い主力への依存は、年齢・控えの力・継承時期と合わせて見る。

## 10分の構成

| 時間 | 内容 | ねらい |
| --- | --- | --- |
| 0:00–0:30 | 導入 | 「ドラフトで補強すべきポイントはどこか」と問い、3候補を提示 |
| 0:30–1:15 | 判断基準 | 4つの評価軸を説明 |
| 1:15–3:30 | Chapter 1：チームの振り返り | チーム全体の攻撃・投手の特徴を振り返り、チーム成績だけで個別ポジションの結論を出さない |
| 3:30–4:30 | 年齢×登録ポジション | 選手層の年齢構成を確認。登録位置と実際の起用は別の情報として扱う |
| 4:30–5:00 | 守備位置別の先発とDH | 既存の外野起用素材で実際の起用を見る。先発分散だけで不足とは判断しない。翌年のDH制は短く補足 |
| 5:00–6:10 | 遊撃 | 主力と二番手以降、ファーム候補を比べ、欠場時の備えを検討 |
| 6:10–7:20 | 捕手 | 主力・控えの攻守とファーム候補を見て、代替の準備度を検討 |
| 7:20–8:30 | 先発投手 | 上位候補の実績を認めた上で、次のローテ候補と役割の準備度を検討 |
| 8:30–9:20 | 3候補の整理 | 各候補の根拠・反証・未確認点を並べ、序列は保留 |
| 9:20–10:00 | 締め | ドラフト後に役割・時間軸・現有戦力との重なりを答え合わせすると予告 |

## 以前の絵コンテから活かすもの

- チーム振り返りの4スポット
- 年齢×登録ポジションの表
- 外野の守備位置別先発図と棒グラフアニメーション
- 補強候補を比べる4つの評価軸
- DHと若手打者の調査素材（表計算画面はそのまま動画に貼らず、必要に応じて画面化）

これらを残し、新しく作成した遊撃・捕手・先発投手のスポットへつなぐ。年齢構成と実際の起用は独立したカットにする。

## 表現・確認ルール

- 怪我や離脱を事実のように語らず、「主力が欠場した場合」の備えとして表現する。
- 年間打撃成績を守備位置別打撃成績と誤認させない。
- 投手の年間投球回を先発投球回と混同しない。
- ファーム成績だけで一軍の即戦力と判断しない。
- 数値入りの画面は制作中素材として扱う。独立資料との照合とデータ・図版の利用条件確認後に公開値を確定する。
- 画面は一つの問いに一つの答えを対応させ、出典情報は説明欄と制作台帳で管理する。
