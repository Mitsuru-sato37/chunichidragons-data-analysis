# ショート動画制作の心得

更新日: 2026-10-26
適用範囲: 野球選手紹介・データ分析など、今後制作するショート動画全般

Google Drive正本: [ショート動画制作の心得](https://docs.google.com/document/d/1fpFAr4NGkehtTkfekSGoeVSomT2GSUUZkdlRsdoSV5Y/edit)

## 構成と情報量

- 最初に動画の問いを一つ決め、視聴後に残したい答えも一文で置く。
- ナレーションを先に決め、各画面がどの一文を支えるかを対応づけてから素材を作る。
- 一画面につき主張は一つ。情報を制限して見せ場を作り、不要な数字・説明・装飾は入れない。
- 経歴、武器・実績、課題、まとめなど、役割の違う情報は画面を分ける。視聴者がすでに知っている氏名やテーマは繰り返しすぎない。
- 最後はテーマに沿う問いや一言で締める。視聴者に分析手順を教える説明は、動画の目的に必要な場合だけ入れる。

## 根拠と分析

- 確認済み事実、報道・スカウトなどの評価、集計値、分析上の見立て、未確認事項を区別する。
- 指標には比較対象・期間・母数・定義を添え、数値が動画内で何を示すのかを短く説明する。春秋比較などは対象範囲を揃える。
- 指標の差から原因まで断定しない。たとえばERAとFIPの差だけからゴロ傾向や守備の影響を断言せず、ゴロ率などの根拠がなければ保留する。
- K/BBや投球回あたり球数から制球面を読むときは、記録上の変化と原因の推定を分ける。球ごとの位置やカウントを確認できない限り、四球の性質まで決めつけない。
- スカウト評と実績が異なるときは、片方を消さず、その差を動画の論点にする。事実にない因果関係を足さない。
- 動画画面に出典を表示しない場合も、検証用メモには出典URL・確認日・対象期間を残す。

## 見た目と編集

- 写真や映像を使うかは動画ごとに決める。写真なしでも成立する構成を選べるようにし、AI生成らしい人物画像はユーザーが希望しない限り使わない。
- 既定の見た目は明るく読みやすくする。黒一色の背景や過剰な装飾、文字の詰め込みは避ける。
- DaVinci Resolveを案内するときは、実際の画面にある機能名を確認し、「タイトル」「Text+」「Fusionタイトル」を混同しない。まず短い範囲で試し、操作と見え方を確認してから本編へ広げる。
- 効果音は場面転換ごとに入れず、冒頭のタイトル表示など意味のある箇所に絞る。最後の問いかけは、まずBGMを残して効果音なしで締める。
- 完成確認は静止画だけでなく、縦型プレビューをスマートフォン相当の表示サイズで行い、文字の読みやすさ、重なり、安全余白、音量を確かめる。

## 次回の標準手順

1. テーマとなる問いと視聴後に残す答えを決める。
2. ナレーションを作り、事実・評価・分析・未確認を区別する。
3. ナレーションの各文に必要な画面を割り当て、不要な要素を削る。
4. 数値の期間・母数・定義・出典を確認する。
5. 冒頭・中盤・締めを短いプレビューで見て、文字・動き・音を調整する。
6. 採用版だけを正規の保存先に置き、試作は作業場所に分ける。

## 宮原廉ショートで確認した具体例

- 「先発か、中継ぎか」を動画全体の問いに置き、経歴、武器・実績、能力と懸念、まとめを順に分けた。
- 「スカウト評では制球が評価される一方、秋の指標には課題が表れている」という評価とデータの差を論点にした。
- 「あなたは先発派？中継ぎ派？」を締めに置いた。
- 冒頭はタイトル表示に効果音を一度使い、締めはBGMを残して効果音なしにする案を採用候補とした。
