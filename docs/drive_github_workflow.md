# 中日ドラゴンズ動画候補の保存手順

更新日: 2026-10-30

この文書は中日ドラゴンズの動画候補の置き場所を定める。リポジトリ全体のDrive/GitHubの役割、作業記録、終了手順は[運用手順](repository_workflow.md)を参照する。

## 候補の置き場所

- 動画候補の一覧と状態は、このリポジトリの [動画候補一覧](video_idea_index.md) を正本とする。
- 公開可能な候補の詳細は docs/ideas/YYYY-MM-DD_短い題名.md に記録する。Publicリポジトリには公開できる内容だけを置き、非公開の企画詳細・個人情報・非公開DriveのタイトルやURLは置かない。
- Google Driveの[#00動画](https://drive.google.com/drive/folders/1H7slO6oDXrmovUFSsCajXQYusi78TNkM)は調査資料・取得資料・共有成果物の保存先とする。新しい候補メモの正本には使わない。
- 既存のDrive企画メモは旧正本としてそのまま保持し、この作業では移動・上書き・削除しない。公開可能性を確認して移行を決めるまでは、詳細の複製や非公開リンクの掲載を行わない。
- 候補が制作対象に決まったら、制作素材は既存の動画案件フォルダ（現在のドラフト案件は[#L1ドラフト](https://drive.google.com/drive/folders/1mA5AJzEdN2lI1iYn2YLoJYb8102o1EoH)）に整理する。Drive上の調査資料はリポジトリの作業記録から参照する。
- チャンネルに限定されない共通ルール等のアイデアは AI-Workspace/00_Inbox に保存する。同じメモを複数の場所へ作らない。
