# 中日ドラゴンズ動画候補の保存手順

更新日: 2026-10-30

この文書は中日ドラゴンズの動画候補の置き場所を定める。リポジトリ全体のDrive/GitHubの役割、作業記録、終了手順は[運用手順](repository_workflow.md)を参照する。

## 候補の置き場所

- 動画企画の候補は、中日ドラゴンズ作業フォルダ内の「#00動画」に保存する: [#00動画](https://drive.google.com/drive/folders/1H7slO6oDXrmovUFSsCajXQYusi78TNkM)
- 中日ドラゴンズの作業フォルダ: [Driveフォルダ](https://drive.google.com/drive/folders/1-cWK3yDF8W3UKa73XXaX0pmkapn7X-hv?usp=drive_link)
- 現在登録している候補は[動画候補一覧](video_idea_index.md)を参照する。ユーザーが「中日の動画案ない？」などと尋ねたら、この一覧とDriveの候補フォルダを確認し、既存候補を新案と並べて提示する。
- 候補が制作対象に決まったら、企画メモは候補として保持し、制作素材は既存の動画案件フォルダ（現在のドラフト案件は[#L1ドラフト](https://drive.google.com/drive/folders/1mA5AJzEdN2lI1iYn2YLoJYb8102o1EoH)）に整理する。候補メモを丸ごと複製せず、GitHubの引き継ぎから正本にリンクする。
- チャンネルに限定されない一般的なアイデアメモは、引き続き `AI-Workspace/00_Inbox` に保存する。動画候補フォルダとInboxの両方へ同じメモを作らない。
