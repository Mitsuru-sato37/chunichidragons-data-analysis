# リポジトリ作業と引き継ぎの手順

更新日: 2026-10-30

## 保存先と連携

プロジェクト固有のアイデアはGitHubリポジトリを正本とし、公開可能な動画候補は docs/video_idea_index.md と必要に応じて docs/ideas/ に記録する。Google Driveには共有成果物・調査資料・取得資料を保存する。Publicリポジトリには公開可能な内容だけを記録し、非公開の企画詳細やDriveのタイトル・リンクを記載しない。元データ・結合データ・派生レポートなど、このリポジトリのルールでGit対象外のものはローカルに置く。

共通ルールの正本は[Google Driveの「AI作業ファイル管理ルール」](https://docs.google.com/document/d/1SRV0Fn30bMyUeWZA4EbHf31eqJlPPef_ue8YBVASXdU/edit)。DriveとGitHubは自動同期されないため、Driveに成果物を保存したら、読み戻して確認し、確認済みリンクをGitHubの該当する作業記録に残す.
## 作業ごとの記録

1. 着手時にリポジトリの既存文書、保存先、Git差分を確認する。
2. 変更や調査の内容に応じて、コード・ルール・該当テーマの引き継ぎ文書を更新する。記録には目的、判断、変更ファイル、検証、未解決事項、次の作業を含める。
3. Gitには今回の作業で変更したファイルだけをステージし、差分を確認してコミットする。無関係な変更を混ぜない。別PCからの再開に必要なpushは、会話の終了ルールとユーザーの指示に従う。
4. 調査資料・取得資料・成果物をDriveに保存した場合は、読み戻して確認済みリンクと更新内容をGitHubの作業記録へ追記する。Drive資料本文はGitHubへ複製しない。企画アイデアの正本は別途リポジトリで管理する。

## データ分析リポジトリ固有の扱い

このリポジトリでは `AGENTS.md` と `.gitignore` に従い、元ZIP/CSV、結合データ、派生レポートをGitへ入れない。データ利用権が不明な数値や資料は、共有Driveへ保存・公開する前にも確認する。手順・指標定義・結果を含まない方法論メモは、目的に応じて追跡対象の `docs/` に保存できる。

## 会話終了とアーカイブ

ユーザーが「お疲れ」と伝えたら、作業差分を確認し、今回の作業分だけをコミットする。指示に沿ってpushやPRの状態も確認し、コミット、検証、未解決事項をGitHubの記録と完了報告へ残す。その後、毎回「この会話をアーカイブしてよいですか」と確認する。明示的な了承を受けるまではアーカイブしない。
